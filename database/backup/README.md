# Sao lưu và phục hồi database

Quy trình cài đặt, sao lưu, phục hồi, lưu trữ backup và mẫu biên bản diễn tập nằm trong [tài liệu CSDL](../../docs/ops/database-installation-backup-restore.md).

Các file dump phải được lưu ngoài repo, giới hạn quyền truy cập và không commit lên Git. Repo chưa ghi nhận một lần diễn tập restore PostgreSQL thật; cần cập nhật biên bản trong tài liệu trên sau khi thực hiện.
